# Terminal basics

A shell runs commands and starts programs. UKUI remains the normal desktop; learning a shell helps you understand system operations.

Read-only exercises:

    pwd
    ls -la
    printf 'Hello, Kirin!\n'
    man ls

`pwd` shows your location; `ls -la` displays hidden files; `printf` writes text to the terminal; `man` reads installed reference material.

**Exercise:** Find your home directory, list it, then use `man pwd` to look up `-L`. Exit the manual with `q`. None of those commands modifies files.
